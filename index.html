Etiquetas de códigos

Ajusta el texto si no coincide con el criterio real de tu servicio, o añade/elimina etiquetas propias. Eliminar una etiqueta no borra los días ya marcados con ese código.
Clic en una celda (en modo edición) y escribe el código (T, V, P, IM, B o C) — Intro para guardar, Esc para cancelar. Fines de semana bloqueados. Las filas INICIO / FC / REUNIÓN (arriba de la tabla) marcan eventos por día — clic para activar o desactivar cada uno; pueden coincidir varios el mismo día. Sin contraseña solo se pueden ver los datos y pedir cambios con «Solicitar cambio».
Los datos se guardan automáticamente y son visibles para cualquier persona que abra esta app. · No sustituye al registro oficial de RRHH.
